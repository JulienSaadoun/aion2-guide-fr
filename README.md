# Aion 2 – Guides FR

Guides de classe pour Aion 2 (version globale, saison 1, niveau 45), en français, avec les noms de compétences du client français suivis de l'anglais.

- Page en ligne : https://juliensaadoun.github.io/aion2-guide-fr/gladiateur.html
- Le contenu de `gladiateur.html` est généré par `tools/build.py` à partir de `tools/sections/*.html` (`python3 tools/build.py`).
- Icônes : `assets/icons/`.

Guide non officiel. Aion 2 est une marque de NCSOFT.
